# Security Policy

## Reporting a vulnerability

Please report security issues to umair64066@gmail.com.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/umairrrkhan/Voxgig/issues

## Scope

This policy applies to the generated Umair Khan SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the OpenHolidays API v1 public API, generated by
Umair Khan. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
